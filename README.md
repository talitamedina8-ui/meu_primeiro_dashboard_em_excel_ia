Meu Primeiro Dashboard em Excel IA

Sobre o projeto

Dashboard desenvolvido para importar dados de planilhas Excel e apresentar estatísticas de forma visual e organizada.

Informações

Aluno: Talita

Curso: Inteligência Artificial

Data: 26/09/2026

Objetivo

Criar um dashboard simples e intuitivo capaz de importar arquivos Excel e apresentar informações resumidas por meio de indicadores e gráfico.

Funcionalidades

Importação de arquivos Excel (.xlsx e .xls)

Importação de arquivos CSV

Contagem de linhas importadas

Contagem de colunas

Contagem de valores numéricos

Gráfico com as três estatísticas

Atualização automática após a importação

Tecnologias utilizadas

HTML5

CSS3

JavaScript

SheetJS (XLSX) para leitura de arquivos Excel

Chart.js para criação do gráfico

Como utilizar

Abra dashboard_talita_excel.html em um navegador.

Clique em Importar Excel.

Selecione uma planilha .xlsx, .xls ou .csv.

O dashboard processará os dados automaticamente.

Confira as estatísticas e o gráfico atualizado.
